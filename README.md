## react-portuga

Este repositório contém uma coleção de exercícios para aprender React.js. 

**Objetivo:**

* Fornecer um ambiente estruturado para praticar os conceitos básicos do React.
* Incentivar o aprendizado prático através de exemplos e desafios.
* Ensinar as melhores práticas de desenvolvimento React.

**Conteúdo:**

O repositório está organizado em pastas, cada uma contendo um exercício específico:

* **fundamentos:** Exercícios que exploram os conceitos básicos do React, como componentes, props, state, JSX e eventos.
* **listas-e-condicional:** Exercícios que exploram o uso de listas e condicionais no React.
* **formulários:** Exercícios que envolvem a criação e manipulação de formulários.
* **hooks:** Exercícios que introduzem os hooks do React, como useState, useEffect, useMemo e outros.
* **roteamento:** Exercícios que exploram o uso de roteamento no React com bibliotecas como React Router.

**Como usar:**

1. Clone o repositório: `git clone https://github.com/josebrenon/react-portuga`
2. Navegue até a pasta do exercício desejado.
3. Execute o comando `npm install` para instalar as dependências.
4. Execute o comando `npm start` para iniciar o servidor de desenvolvimento.
